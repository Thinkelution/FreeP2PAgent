A SMALL APP. A SHORTER PATH.

Make the connection.
Then make it yours.

01 / SETTLE IN

Meet your tray companion.

Install the agent and pick a name. Your device creates its own cryptographic identity. Close the window; the agent stays in your tray.

02 / FIND YOUR PEOPLE

Exchange an invite.

Share your invite code through a channel you trust. Add a friend and accept the request on the other end. You control who gets in.

03 / SEND SOMETHING

Talk. Transfer. Stay close.

Send messages or offer a file up to 10 GB. Your friend chooses where to save it. Transfers stream to disk and verify file integrity.

↔

Direct first. A relay when needed. Our coordinator introduces online peers. Google STUN helps discover a route; our TURN relay on server 208 carries encrypted traffic when a direct connection cannot be established. Both friends need to be online.

v0.1.0FIRST PREVIEW22 October 2026

A direct line to your friends.

  • Windows, macOS and Linux tray apps, built with GitHub Actions.
  • Device identities, invite codes, mutual friend requests and blocking.
  • Encrypted WebRTC chat with delivery acknowledgments.
  • File offers, save dialogs, progress, cancellation and SHA-256 verification.
  • Hosted signaling and authenticated TURN fallback.
What to know before you try it

This is an early MVP, not a security-audited release. Chat history is stored locally without at-rest encryption. Peers can see each other's IP addresses; the coordinator handles identity, presence and connection metadata.

Both peers must be online. Interrupted files must be resent. Android, auto-updates, identity recovery, offline messaging and GPU inference are not available yet. Native CI covers all four desktop targets; physical Mac direct-LAN testing remains outstanding.

We imagine a network where trusted peers can lend spare GPU capacity for inference. Your agent could find an available machine, request a model task and return the result—with the owner's permission.

FUTURE DIRECTION
