# FreeP2PAgent v0.1.0 — Desktop preview

First public desktop preview for Windows x64, macOS Apple silicon and Intel, and Linux x64.

- Tray companion with a local device identity and OS-protected private key.
- Invite codes, mutual friend requests, contact removal and blocking.
- WebRTC encrypted chat with delivery acknowledgments.
- File transfers up to 10 GB with receiver approval, save dialogs, streaming, progress, cancellation and SHA-256 integrity verification.
- Hosted coordinator, Google STUN discovery and authenticated TURN fallback on server 208.

## Installation

Choose the `.exe` for Windows, the appropriate `.dmg` for your Mac, or `.AppImage` / `.deb` for Linux. ZIP archives are also available. Checksums are in `SHA256SUMS.txt`.

These preview packages are unsigned; macOS builds are not notarized. Linux requires an unlocked Secret Service keyring, and tray support varies by desktop. See the [README](https://github.com/Thinkelution/FreeP2PAgent#readme) for setup details.

## Known limitations

Both friends must be online. Interrupted files must be resent. Local chat history is not encrypted at rest. Direct peers can see IP addresses; the coordinator sees identity, presence and signaling metadata. This is not a security-audited release. Each installation has its own identity; identity recovery, auto-updates, Android, offline messaging and GPU inference are not implemented.

Native CI passed on all four targets. Windows and Linux integration tests exercised direct connections; macOS CI exercised the external relay. Physical Mac direct-LAN validation remains outstanding.

Packages come from the successful [native CI run](https://github.com/Thinkelution/FreeP2PAgent/actions/runs/39829261419) for commit `bc95ed981b91789ed8715ce6d4f6820d55bdec6b`.

## Future vision

Opt-in GPU inference between trusted peers: capability discovery, explicit job approval, usage limits and cancellation. A machine running inference may see task inputs; isolation and permission boundaries need to be designed and validated before release. This is planned work, not a feature of v0.1.0.
